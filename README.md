## Ідеї розв'язків

1. Рекурсивно: два дерева однакові, якщо однакові корені, ліві піддерева і праві піддерева.
2. Дерево симетричне, якщо ліве піддерево - дзеркало правого: ліве ліве має
   збігатися з правим правим, а ліве праве - з правим лівим.
3. Рекурсивно міняємо місцями лівого й правого нащадків у кожному вузлі.
4. Inorder-обхід BST видає значення в порядку зростання; обходимо дерево
   стеком і зупиняємось на k-му вузлі.
5. Серіалізація - обхід у ширину, відсутні вузли записуються як `null`:
   `[1,2,3,null,null,4,5]`. Десеріалізація читає значення тим самим порядком,
   по черзі роздаючи вузлам з черги лівого і правого нащадків.
6. Для кожного вузла рахуємо найкращий шлях униз (`gain`); шлях, що
   "згинається" у вузлі, дорівнює `val + gain(ліве) + gain(праве)` -
   серед таких шукаємо максимум. Від'ємні гілки не беремо.
7. Жадібно знизу вгору: кожен вузол повідомляє батькові один зі станів
   "без нагляду", "під наглядом", "з камерою". Якщо нащадок без нагляду,
   ставимо камеру у вузол. Так камери ставляться над листками, а не на листки.
8. Обходимо дерево й записуємо трійки `(стовпець, рядок, значення)`. Сортування
   трійок дає потрібний порядок: за стовпцем, зверху вниз, при однаковій
   позиції - за значенням. Потім групуємо за стовпцями.
9. Кількість тире - глибина вузла. Стек зберігає шлях від кореня; для вузла
   глибини d батьком є вузол на глибині d - 1. Перший нащадок - лівий, другий - правий.

Рекурсивні розв'язки 6-8 збільшують межу глибини рекурсії Python
(`sys.setrecursionlimit`), бо дерево з умови може бути "ланцюжком" до 30 000
вузлів. Тести перевіряють і такий випадок.

Приклад 3 задачі 2 у методичці повторює приклад із задачі 1 (`p = [1,2,1],
q = [1,1,2]`). Для перевірки симетричності кожне з цих дерев перевірено окремо:
обидва несиметричні, тобто результат `false` збігається з умовою.

## Запуск

Потрібен Python 3.8 або новіший.

```bash
python main.py
python -m unittest -v
```

## Результат запуску `python main.py`

```text
1. Те саме дерево
  Input: p = [1, 2, 3], q = [1, 2, 3] -> Output: true
  Input: p = [1, 2], q = [1, null, 2] -> Output: false
  Input: p = [1, 2, 1], q = [1, 1, 2] -> Output: false

2. Симетричне дерево
  Input: root = [1, 2, 2, 3, 4, 4, 3] -> Output: true
  Input: root = [1, 2, 2, null, 3, null, 3] -> Output: false
  Input: root = [1, 2, 1] -> Output: false
  Input: root = [1, 1, 2] -> Output: false

3. Інвертувати бінарне дерево
  Input: root = [4, 2, 7, 1, 3, 6, 9] -> Output: [4, 7, 2, 9, 6, 3, 1]
  Input: root = [2, 1, 3] -> Output: [2, 3, 1]
  Input: root = [] -> Output: []

4. K-й найменший елемент у BST
  Input: root = [3, 1, 4, null, 2], k = 1 -> Output: 1
  Input: root = [5, 3, 6, 2, 4, null, null, 1], k = 3 -> Output: 3

5. Серіалізація та десеріалізація бінарного дерева
  Input: root = [1, 2, 3, null, null, 4, 5] -> serialize: [1,2,3,null,null,4,5] -> deserialize + serialize: [1,2,3,null,null,4,5]
  Input: root = [] -> serialize: [] -> deserialize + serialize: []

6. Максимальна сума шляху
  Input: root = [1, 2, 3] -> Output: 6
  Input: root = [-10, 9, 20, null, null, 15, 7] -> Output: 42

7. Камери бінарного дерева
  Input: root = [0, 0, null, 0, 0] -> Output: 1
  Input: root = [0, 0, null, 0, null, 0, null, null, 0] -> Output: 2

8. Вертикальний обхід бінарного дерева
  Input: root = [3, 9, 20, null, null, 15, 7] -> Output: [[9], [3, 15], [20], [7]]
  Input: root = [1, 2, 3, 4, 5, 6, 7] -> Output: [[4], [2], [1, 5, 6], [3], [7]]
  Input: root = [1, 2, 3, 4, 6, 5, 7] -> Output: [[4], [2], [1, 5, 6], [3], [7]]

9. Відновити дерево після preorder-обходу
  Input: traversal = "1-2--3--4-5--6--7" -> Output: [1, 2, 5, 3, 4, 6, 7]
  Input: traversal = "1-2--3---4-5--6---7" -> Output: [1, 2, 5, 3, null, 6, null, 4, null, 7]
  Input: traversal = "1-401--349---90--88" -> Output: [1, 401, null, 349, 88, 90]
```

Тести (`python -m unittest -v`): 9 тестів, усі проходять.
